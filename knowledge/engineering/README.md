# Engineering knowledge

This directory contains reusable implementation lessons: language and test-typing traps, integration harness patterns, time and date testing, UI and browser testing, and small implementation shortcuts. The notes are historical evidence, not current authority. Recheck every applicable claim against the current dependency versions, project skills, routed rules, and code before changing behavior.

- `<topic>.md` — `<one-line scope>` (add a row per note; for example typing/test narrowing, integration test harnesses, time and date testing, UI and browser testing, implementation shortcuts)
- `<agent roster history>.md` — optional dated model/effort tier and boundary decisions for the house agents (history only; the current table is `.claude/rules/agents-roster.md`).

Obligations that must hold on every change belong in path-routed rules (`.claude/rules/`, or `docs/agent-rules/INDEX.md` for Codex), not here. Keep lessons here when they are shortcuts or rationale rather than invariants.

Each curated note names its sources. Writers propose new lessons as knowledge updates; the main thread or an explicitly assigned writer applies them.
